# AI Disclosure

This package and the associated paper used large language models (LLMs)
in three bounded roles. This document records each role with sufficient
specificity that any reviewer can verify the claim against the code.

## Models used

| System | Provider | Approximate access window |
|---|---|---|
| Claude (Sonnet / Opus families) | Anthropic | 2025–2026 |
| ChatGPT (GPT-4 / GPT-4o families) | OpenAI | 2025–2026 |

## Per-stage AI use table

| Pipeline stage | Implementation | AI used? | Role of AI |
|---|---|---|---|
| Source loading (Scopus / WoS / IEEE) | `io/*.py` | No | — |
| Harmonization to unified schema | `harmonize.py` | No | — |
| Cross-database deduplication (union-find) | `dedup.py` | No | — |
| Three-tier screening (I-Core / I-Context / E-Exclude) | `screen.py` | No record-level inference | Authors used LLMs to draft regex patterns and category boundaries; final dictionary in `config/coding_dictionary.v1.0.yaml` was authored and approved by humans. |
| Section-level multi-label mapping | `classify.py` | No record-level inference | Same: dictionary-drafting only. |
| Priority tiering (T1/T2/T3) | `screen.py` | No | Citation thresholds and document-type rules are deterministic. |
| Validation (Cohen's κ, % agreement) | `validate.py` | No | — |
| 525-paper full-text validation panel | (manual; outside this code) | Assistive only | AI used to organize per-paper extraction notes, flag possible omissions in extraction sheets, and consistency-check completed sheets against the dictionary. **No numerical performance value, dataset attribute, citation, deployment claim, or final classification was accepted from AI output without verification by at least one of three human reviewers against the original full text.** |
| Manuscript language polish | (manual) | Assistive only | Selected paragraphs polished for clarity. No analytical claim or numerical value was generated by AI. |

## What AI did NOT do

To prevent any misreading of this disclosure, we state explicitly:

- AI did **not** classify any of the 27,720 records in the corpus.
- AI did **not** assign any sensing modality, paradigm, era, or section
  label that appears in the corpus statistics or any figure / table in
  the paper.
- AI did **not** extract performance values, dataset attributes, or
  deployment claims from any full-text paper without human verification
  against the source.
- AI did **not** make any inclusion / exclusion decision on a per-record
  basis. Every screening label is the deterministic output of the regex
  rules in `config/coding_dictionary.v1.0.yaml`.

## Verifying these claims

Anyone can verify the absence of LLM inference in the corpus pipeline by:

```bash
# 1. Search the source tree for any LLM SDK import or HTTP call to LLM providers
grep -rE "anthropic|openai|api\.openai|api\.anthropic" src/ tests/ scripts/

# 2. Run the entire pipeline with the network disabled
unshare -n make all   # Linux; or use a network-disabled container

# 3. Compare against published hashes
make check-reproducibility
```

The first command should return no matches. The second should produce the
same outputs as a network-enabled run. The third should pass.

## Recommended journal-style acknowledgment

> The authors used Anthropic Claude and OpenAI ChatGPT as auxiliary tools
> for (i) drafting and refining the regular-expression coding dictionary
> and era-taxonomy boundaries used by the rule-based metadata classifier;
> (ii) organizing literature-extraction notes and flagging possible
> omissions in the 525-paper full-text validation panel; and
> (iii) improving language clarity in selected parts of the manuscript.
> No record-level classification, numerical value, citation, deployment
> claim, or final interpretation was accepted from AI output without
> verification by the authors against the original sources.
